# kis-lab 실습 환경 — 시작하기

> 한국투자증권(KIS) API로 **모의투자**를 실습하는 강의 자료입니다.
> **기술 환경 세팅은 AI 코딩 도구가 알아서 해줍니다.** 여러분은 아래 3단계만 따라오면 됩니다.

---

## 딱 3단계

### 1️⃣ 이 폴더를 AI 코딩 도구로 열기

아래 중 **하나**만 쓰면 됩니다 (이미 쓰던 도구가 있으면 그걸로):

| 도구                           | 여는 법                                  | 주의                                                                       |
| ---------------------------- | ------------------------------------- | ------------------------------------------------------------------------ |
| **VS Code + GitHub Copilot** | VS Code로 이 폴더 열기 → Copilot Chat 패널 열기 | 채팅창 하단 모드를 **`Agent`(에이전트)** 로 선택하세요. `Ask` 모드는 명령을 **실행하지 못합니다**(설명만 함) |
| **Claude Code**              | 터미널에서 이 폴더로 이동 후 `claude` 실행          | —                                                                        |
| **Codex CLI**                | 터미널에서 이 폴더로 이동 후 `codex` 실행           | —                                                                        |

> 어떤 도구를 쓰든 이 폴더의 지시파일(`CLAUDE.md`·`AGENTS.md`·`.github/copilot-instructions.md`)을 자동으로 읽습니다 — 세 파일은 내용이 같습니다.
> 아직 도구가 하나도 없다면 교수님이 안내한 도구를 먼저 설치하세요.

### 2️⃣ `setup` 이라고 입력하기

채팅창에 **`setup`** (또는 `설치해줘`)이라고만 입력하세요. 그러면 AI가 자동으로:

- `uv`(파이썬 패키지 매니저) 설치
- Python 3.12 + 필요한 패키지 설치
- JupyterLab + Notebook 커널 설치
- `.env` 파일 생성
- 환경 검증

까지 알아서 진행합니다.

### 3️⃣ 사람이 직접 할 일은 1가지뿐 (기본 실습 기준)

| 언제 | 할 일 | 시간 |
|------|-------|------|
| setup 도중 (안내가 뜨면) | `.env` 파일에 KIS **모의투자** 키 4개 입력 | 약 2분 |

> 📌 **코어 lab02~lab04는 Docker 없이 완료됩니다.** `lab04`는 동봉된 CSV로 백테스트와 dry-run 주문 미리보기를 실행합니다. Docker/Lean 백테스터는 더 정교한 체결 모델을 다루는 **선택 심화 단계**이며, 교수 안내 후 진행하세요.

`.env`에 넣을 4개 — KIS Developers 포털에서 발급(<https://apiportal.koreainvestment.com> → **API 신청 → 모의투자** 탭):

```dotenv
KIS_MOCK_APP_KEY=
KIS_MOCK_APP_SECRET=
KIS_MOCK_ACCOUNT_NUMBER=      # 모의 계좌번호
KIS_MOCK_ACCOUNT_PASSWORD=
```

> `KIS_MODE=mock` 과 `KIS_ACCOUNT_PRODUCT_CODE=01` 은 **이미 채워져 있습니다 — 수정하지 마세요.**

## 실습 시작

setup이 끝나면 노트북을 먼저 엽니다:

```bash
uv run jupyter lab
```

브라우저에서 아래 순서로 엽니다.

| 흐름 | 열 파일 | 오늘 성공 경험 |
|------|---------|----------------|
| 전반부 | `lecture/Week14/practice/FD-14-900__trading-practice-student.ipynb` | 토큰 → 계좌/금액 확인 → 1주 모의 주문 → MCP 질문 |
| 후반부 | `lecture/Week14/practice/FD-14-910__backtest-analysis-student.ipynb` | IC 전략 → KIS 수량/주문 후보 → 백테스트 → 결과 읽기 |

**수업에서 각 lab의 역할:**

| 구간 | 역할 | 학생이 확인할 것 |
|------|------|----------------|
| `lab01` | (참고용) 토큰 데모 | `get_token()` 캐시 흐름 |
| `lab02` | 스캐폴딩 확인 2 — 현재가 | 현재가 조회가 되는지 |
| `lab03` | 스캐폴딩 확인 3 — 계좌/주문 | 잔고 조회와 모의 주문 함수 |
| `lab04` | 백테스트 데모 | sample strategy 아이디어 → 백테스트 결과 |

코드 파일 실습이 필요하면 채팅창에 입력하세요:

| 입력 | 실습 |
|------|------|
| `lab02` | 현재가 조회 |
| `lab03` | 모의 주문 (기본은 잔고조회 — 주문은 교수 안내 후) |
| `lab04` | 백테스트 → 모의 주문 dry-run 연결 데모 (Docker 불필요) |
| `검증` | 환경 점검 |
| `오류 해결해줘` | 에러 메시지 자동 분석·수정 |

> 그 외 명령(`MCP 연결해줘`, `백테스트 환경 만들어줘` 등)은 지시파일 `CLAUDE.md`에 더 있습니다.

## 막히면

- 무엇이든 막히면 채팅창에 **`오류 해결해줘`** 라고 입력하세요. AI가 원인을 찾아 고쳐 줍니다.
- ⚠️ 강의는 **모의투자(mock)** 가 기본입니다. 실전(live) 전환은 **반드시 교수 안내 후에만** — 실전은 실제 돈이 움직입니다.
